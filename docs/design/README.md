# Frame design references

Created with the built-in ImageGen tool before React implementation. These are inspiration boards, not application assets or representations of working features. The actual UI uses styled-components and native accessible controls. Source claims shown in generated mockups are illustrative; the application displays actual media credits only.

- `workspace-states.png`: idle, generating, and completed workspace states.
- `component-reference.png`: reusable UI primitives and visual foundations.

## Workspace prompt

Use case: ui-mockup. Create a polished UI design reference board for a web app called Frame, an automated three-scene educational video generator. Landscape board with three compact desktop screen states side by side: idle, generating, complete. Light creative studio aesthetic, warm ivory #f7f6f2 background, white cards, near-black text, muted gray borders, vivid burnt orange #d95935 accent. Editorial clean sans typography. Each screen: small Frame logo, header 'A little idea. A moving story.', left topic form and three production stages, right tall 9:16 video preview. Idle uses soft orange abstract placeholder. Generating shows step indicators, complete shows portrait landscape video, play button, download button and source credits. Compact, restrained, practical, accessible, no sidebar no fake complex controls. This is a reference for real React implementation. Include labels IDLE, GENERATING, COMPLETE above states.

## Component prompt

Use case: ui-mockup. Reusable React component design reference sheet for Frame, a light creative studio automated video app. Warm ivory #f7f6f2 canvas, white surfaces, charcoal typography, subtle gray borders, burnt orange #d95935 primary accent. Clean editorial sans. Grid of clearly labeled component examples: Button (primary orange, secondary white outline, disabled), Topic text field with label and character count (default, focused, error), Card, Status badge (ready, working, error), Progress steps with numbered circles and completed check, Empty state with abstract peach landscape. Include small theme swatches and typography samples. Generous whitespace, polished restrained product design, realistic readable UI, no gradients on controls. Landscape reference sheet, not code.

The implementation uses a darker orange for better text contrast. It intentionally omits controls and claims in the boards that do not correspond to implemented functionality.
